# Workout Tracker

A Windows desktop application built with C# and Windows Forms for planning and logging gym workouts.

## Features
- Create your own workouts (e.g. Push, Pull, Legs)
- Add exercises to each workout
- Log sets, reps and weight for every exercise
- Keep track of your training progress
